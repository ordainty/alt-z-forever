# Alt+Z Forever

Responsively fades the UI when you're not using it, as if you've pressed Alt+Z! Lets you set the fade behavior of every element separately so the UI is exactly as immersive as you want.

A World of Warcraft: Forever addon. Everything comes back on combat, targeting or mouseover.

## Install

Install it with your addon manager from CurseForge or Wago. To install by hand, unzip it into your WoW: Forever folder under `Interface\AddOns\`, in a folder called `alt-z-forever`. The [install page](https://ordainty.github.io/alt-z-forever/install) walks you through it.

## Quick start

1. Type `/azf menu` or select the addon's minimap button to open the settings window.
2. Bind the keys you want under **Keys**. The addon doesn't bind keys for you, so it can't clash with any of yours.
3. Fade mode is already on. Use your toggle key or `/azf toggle` to switch it off and on.
