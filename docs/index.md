# Alt+Z Forever

Responsively fades the UI when you're not using it, as if you've pressed Alt+Z! Lets you set the fade behavior of every element separately so the UI is exactly as immersive as you want.

Your action bars, unit frames, minimap, chat and quest tracker all fade out, and so do other addons' frames. What's left is the world.

Nothing's out of reach, though. Combat brings back most of the interface. Picking a target shows your target and player frames. Casting a spell brings your bars back for a few seconds, even if the cast fails. And when you move the mouse over something faded, it's back instantly, usually along with its neighbours.

Inside dungeons, raids, battlegrounds, arenas and scenarios, nothing fades unless you want it to. See [In instances]({{ site.baseurl }}{% link how-it-works.md %}#in-instances).

## Quick start

The first time you log in, a welcome window shows your keys and how to use them. Type `/azf welcome` to see it again.

1. Type `/azf menu` or select the addon's minimap button to open the settings window.
2. Under **Keys**, select **Open key bindings** and bind the keys you want. The addon doesn't bind keys for you, so it can't clash with any of yours. See [Keybinds and commands]({{ site.baseurl }}{% link keybinds-and-commands.md %}).
3. Fade mode is already on when you log in. To switch it off and back on, press your **Toggle fade mode** key or type `/azf toggle`.
